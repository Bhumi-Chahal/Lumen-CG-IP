# Lumen: Light Reveals Reality

A Python/Pygame computer graphics project. This contribution is the **standalone Level 1: Awakening** prototype, imported from the existing local project in twelve tested feature commits.

Explore an ancient temple, find a lantern, discover three keys and read environmental clues to identify the key that opens the exit. Completing this version offers replay or the main menu. Later levels are not included.

## Run

Install Python 3.12 or newer, then run from the repository root:

```sh
python -m pip install -r requirements.txt
python src/main.py
```

On Windows, `run.bat` uses the Python launcher. The previous team image-processing demo remains available separately:

```sh
python src/pipeline_demo.py
```

## Controls

| Input | Action |
|---|---|
| WASD / arrows | Walk |
| E | Pick up lantern, inspect objects, read clues, open the door panel |
| L | Toggle collected lantern |
| I | Inventory and journal |
| 1 / 2 / 3 at the exit | Try Bronze / Silver / Gold key |
| Space | Hop; dismiss introduction; replay after completion |
| C / H | Controls guide |
| F11 | Fullscreen/windowed |
| Esc | Dismiss panel, return to menu or exit from menu |

## Code

- `src/main.py`: menu, game loop, Level 1 input and completion.
- `src/content/level1.py`: original temple geometry, objects, puzzle and Python-drawn world.
- `src/engine/`: required movement, collision, lantern, lighting, camera and key/journal inventory.
- `src/systems/`: clue panels, key/journal UI and procedural sound.
- `src/pipeline_demo.py`, `src/processing/`, `src/gui/`: preserved team scaffold and OpenCV demo.
- `tests/`: Level 1-only regression and integration checks.

All game visuals and sound effects are generated by Python code. The game does not require image or audio asset downloads. Local dependencies, saves and caches are excluded from Git.

## Tests

```sh
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Tests use dummy SDL video/audio and include collision traversal through the temple, collection of all keys and clues, the door trial, completion and replay. The original Level 2 battery check was excluded from the local Level 1 test module for this standalone contribution.

## Contribution sequence

Part 1 (`Jiya-level1-foundation`) contains setup, application loop, player, temple geometry, camera and lantern. Part 2 (`Jiya`) adds keys, clues, exit logic, menu/journal, original atmosphere and complete validation. These are real staged-import commits of an already developed local prototype.
