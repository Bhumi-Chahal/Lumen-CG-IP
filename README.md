# Lumen: Light Reveals Reality

Lumen is a 2D light-based puzzle adventure game developed as a Computer Graphics and Image Processing project. The game is set inside a mysterious ancient temple where the player must use light to explore the environment, solve puzzles, avoid dangers, and find the correct path to freedom.

The main idea of the game is that light is not only used for visibility but also acts as an important gameplay element.

## Game Overview

The player explores a dark temple using a magical lantern. Different levels introduce new challenges involving light, shadows, mirrors, colors, hidden objects, and puzzles.

As the player progresses, they collect useful objects such as keys, mirror pieces, and crystals. These objects become important in later levels and can help the player during the final challenge.

The game contains five levels, with each level introducing a different light-based challenge.

## Main Features

- Light-based exploration
- Light and shadow puzzles
- Mirror reflection mechanics
- Different lantern colors with different uses
- Hidden objects and pathways
- Lantern battery and recharge system
- Shadow-based enemies and obstacles
- Collectible keys, mirrors, and crystals
- Combination puzzle using collected objects
- Final four-door puzzle
- Multiple possible endings

## Computer Graphics and Image Processing

The project uses Computer Graphics and Image Processing concepts to create its visual and gameplay mechanics. These include 2D graphics rendering, lighting effects, color manipulation, visibility effects, image processing, collision detection, and light-based interactions.
